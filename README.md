# 🏔️ Kashmir Tourism Web Application

A responsive, multi-page web platform designed to showcase the culture, destinations, and travel experiences of Kashmir. Built using semantic HTML5, modern CSS3 layout techniques, and JavaScript.

---

## 📸 Overview & Features

* **Responsive Layouts:** Built with modern CSS Grid and Flexbox for seamless viewing across desktop, tablet, and mobile devices.
* **Custom Styling Architecture:** Utilizes modular CSS variables/tokens and clean global stylesheets (`styles.css`) for consistent design across pages.
* **Interactive UI Elements:** Clean navigation bar, destination highlight grids, and travel inquiry sections.
* **Multi-Page Structure:** Dedicated pages/sections for major attractions, itineraries, and visitor guidelines.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Styling & Layout:** Modern CSS Grid, Flexbox, Custom CSS Tokens/Variables
* **Tools & Editor:** VS Code, Git
